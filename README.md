# 珊的美甲紀錄

一個部署在 GitHub Pages 的美甲紀錄網頁，資料存在 Google 試算表，圖片與影片存在 Google 雲端硬碟。

```
你的瀏覽器 (GitHub Pages 網頁)
        │  fetch()
        ▼
Google Apps Script（Web App，免費、當作 API 橋接）
        │
        ├─► Google 試算表（存文字資料）
        └─► Google 雲端硬碟（存圖片／影片，回傳網址存回試算表）
```

---

## 檔案結構

```
nail-journal/
├── index.html          網頁主體（新增紀錄／紀錄明細／時間軸 三分頁）
├── style.css            樣式（莫蘭迪淺綠色系）
├── app.js                前端邏輯
├── config.js             填入你的 Apps Script 網址
└── apps-script/
    └── Code.gs           貼到 Google Apps Script 的後端程式
```

上傳到 GitHub 的只有根目錄 4 個檔案：`index.html`、`style.css`、`app.js`、`config.js`。
`apps-script/Code.gs` 只需要貼到 Google Apps Script 編輯器裡，不用放進 GitHub。

## ⚠️ 這個版本改了什麼（重要）

相較於第一版，試算表欄位變成：

| 日期 | 施作部位 | 款式金額(NTD) | 卸甲金額(NTD) | 優惠/特殊費用(NTD) | 總額(NTD) | 參考款式圖片 | 施作款式圖片 | 施作影片 |
|---|---|---|---|---|---|---|---|---|

多了 **施作部位** 這一欄，插入在「日期」後面。因為這會讓原本的欄位順序整個往後移一格，
**建議先把試算表裡現有的測試資料列刪掉（只留標題列或清空整張表）**，再重新部署新版 `Code.gs`，
讓程式自動幫你建立正確的標題列，之後的新資料就不會跑錯欄位。

> 如果你已經有想保留的正式資料，改用手動方式：在試算表「日期」欄右邊手動插入一欄、
> 標題打「施作部位」，並幫舊資料補上部位資訊即可。

## 部署步驟

### 1. Google 試算表
維持原本你已建立的試算表即可（`SHEET_ID` 已經內建在 `Code.gs` 裡）。
分頁名稱需為 `紀錄`。

### 2. Google 雲端硬碟資料夾
維持原本你已建立的資料夾即可（`FOLDER_ID` 已經內建在 `Code.gs` 裡）。

### 3. 更新 Google Apps Script
1. 打開你的 Apps Script 專案（就是稍早成功部署過的那個乾淨專案）
2. 把編輯器裡的內容整個換成這次新的 `apps-script/Code.gs`
3. 存檔（Ctrl+S）
4. 右上角 **部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本選「新版本」→ 部署**
   （網址通常不會變，不用重新複製）
5. 如果又跳出授權畫面，一樣選帳號 → Advanced → Go to...(unsafe) → Allow

### 4. 前端 config.js
沿用原本設定即可，`API_URL` 不需要更動（除非你的部署網址真的變了）。

### 5. 上傳到 GitHub
把 `index.html`、`style.css`、`app.js`、`config.js` 上傳覆蓋到你的 GitHub repo 根目錄，
等 GitHub Pages 重新部署（1–2 分鐘）即可看到新版畫面。

## 功能說明

### 📝 新增紀錄
- 日期、施作部位（手／足，下拉選單）
- 款式金額、卸甲金額、優惠/特殊費用：輸入時自動加千分位逗點
- 總額：即時自動加總並顯示千分位
- 參考款式：單張圖片上傳
- 施作款式：**可一次選取多張圖片**，上傳前會自動壓縮（最長邊 1400px）
- 施作影片：選填，單支，建議 45MB 以內（Apps Script 對單次請求大小有限制，過大的影片建議先壓縮或轉檔）

### 📋 紀錄明細
- 表格列出所有紀錄（日期、部位、各項金額、總額）
- 點擊任一列，或按 ✎ 圖示，可跳到「新增紀錄」分頁並帶入資料進行**編輯**
- 按 🗑 圖示可**刪除**該筆紀錄（會二次確認）

### 🗓 時間軸
- 卡片式呈現，新到舊排序
- 每張卡片也有 ✎ 編輯／🗑 刪除按鈕
- 圖片可點擊放大檢視；影片則顯示「觀看施作影片」連結，點擊會在新分頁開啟 Google 雲端硬碟播放

### 編輯行為說明
- 進入編輯模式後，參考款式／施作款式／影片都會顯示目前已儲存的內容
- 參考款式、施作影片：**若沒有重新上傳新檔案，會沿用原本的**；上傳新檔案則直接取代
- 施作款式（多圖）：編輯畫面會列出所有既有圖片縮圖，可個別按 ✕ 移除，也可以再新增更多圖片，儲存時會依畫面上留下的圖片為準
- 編輯完成按「更新紀錄」即會寫回原本那一列，不會產生新的一列
- 想放棄編輯，按「取消編輯」即可清空表單、回到新增模式

## 常見問題

**Q: 送出後畫面顯示「儲存失敗」，但試算表其實有資料？**
最常見原因是**瀏覽器同時登入了多個 Google 帳號**，導致 Apps Script 回應被插入帳號確認頁面而不是乾淨的 JSON。
解法：建立一個 Chrome 專屬設定檔，只登入你建立試算表用的那個帳號，之後都用這個設定檔開啟網站。

**Q: 部署 Apps Script 時一直卡在「無法開啟這個檔案」？**
通常也是多帳號互相干擾造成，建議用無痕視窗、且該無痕視窗裡只登入單一帳號測試。

**Q: 影片上傳很慢或失敗？**
Apps Script 單次請求大小有限制，建議影片控制在 45MB 以內、解析度不需要太高（手機拍攝可先用內建工具壓縮或裁切）。

**Q: 想再加欄位（例如美甲師、店家、心得筆記）怎麼辦？**
在 `Code.gs` 的 `HEADERS` 陣列加欄位、`doPost` 組 `rowValues` 時加對應值，
並在 `index.html` 加輸入欄位、`app.js` 的 `enterEditMode` / `renderTable` / `renderTimeline` 加對應顯示邏輯即可。
